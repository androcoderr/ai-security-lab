# AI Security Lab

A production-grade LLM security research lab.

**Stack:** Flask + Llama3 + PostgreSQL + Redis + Presidio + ChromaDB + Docker

## Security Layers (30+)

- Rate limiting, DLP, keyword filter, semantic similarity
- Crescendo, fictional framing, training extraction detection
- Model hash verification, RAG security, MCP tool scanning
- HTTPS, container hardening, secret management
- Anomaly detection, regression testing, SOC dashboard

## Quick Start
